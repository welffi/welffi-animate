# welffi animate

a roblox r6 animator. it lives inside [welffi hub](https://github.com/welffi/welffi-hub).

## how to download

1. get `whub.exe` from the [welffi hub releases](https://github.com/welffi/welffi-hub/releases/latest) and run it
2. click the welffi animate tile on the home page
3. the hub downloads it and opens it, and tells you when there's an update
